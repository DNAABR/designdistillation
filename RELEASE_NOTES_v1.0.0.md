# Design Distillation v1.0.0

Design Distillation v1.0.0 stabilizes the complete machine-readable design pipeline.

## Highlights

- 51 canonical corpus entries including 30 UX patterns, 9 anti-patterns, and 11 product recipes.
- 24-axis Design DNA with framework-neutral DTCG tokens and three themes.
- Deterministic Composer producing machine, human, and coding-agent contracts.
- Source-owned reusable registry with CSS, Tailwind v4, and React adapters.
- Profile-aware anti-slop auditor with explicit exceptions.
- Static website explorer and bounded Design DNA Lab.
- Focused MCP retrieval with deterministic relevance/compactness benchmarks.
- Stable v1 public schema, CLI, and MCP compatibility manifest.
- Cross-layer semantic regression baseline and deterministic visual-regression fixture.

## Validation

The v1.0 release line preserves the validated RC gates: 68/68 tests passed, retrieval recall 1.0, and compact retrieval ratio approximately 0.0107.
